# Student Performance and Study Habits Analysis

## Project Overview
This project focuses on analysing the Student Performance and Study Habits dataset using R and RStudio. The aim is to explore student study habits and performance through descriptive statistics and data visualization.

## Dataset
- **Source:** Kaggle – Student Performance and Study Habits Dataset
- **Records:** 1,000
- **Variables:** 9

## Tools and Technologies

- RStudio
- ggplot2
- gridExtra

## Skills Used

- Data Visualization
- Statistical Analysis

## Visualizations

- Pie Chart
- Scatter Plot
- Q-Q Plot

## Project Files

To explore student performance and study habits using statistical measures and graphical representations.
